# Security policy

0xTerm runs your shell and reads your files, so security reports matter.

## Reporting a vulnerability

Please don't open a public issue. Email
[allocx@mailbox.org](mailto:allocx@mailbox.org) with a description, the
steps to reproduce it, and the affected version. You'll get a reply within a
week, and a fix or a plan before anything is disclosed.

## Supported versions

Only the latest release gets security fixes.
